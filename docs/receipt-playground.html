What this checks

tool-surface diff proves runtime discovery changes without logging raw schemas/prompts/results.

context attention proves required retrieved context was delivered, acknowledged, and cited before edits.

rule attention shows whether project rules were re-read, cited in the pre-edit plan, and checked before changes.

skill install provenance shows which SKILL.md source path won, which mirrors were ignored, and whether install metadata stayed content-safe.

retrieval adoption shows whether an available graph/RAG tool was actually used before claims, not just configured.

chat recovery turns archived agent chats into resumable search cards: workspace, branch/files, last check, handoff summary, and stale-if.

handoff freshness proves a HANDOFF.md/CONTEXT.md-style artifact still matches the source session, repo state, checks, and referenced files before a new agent resumes.

context diet proves a memory/rule file was promoted only after observed corrections, scoped tightly, and pruned instead of bloating every new session.

context hygiene proves a cleanup plan audited loaded sources, candidate removals, safety negative controls, rollback, and review gates before pruning context.
